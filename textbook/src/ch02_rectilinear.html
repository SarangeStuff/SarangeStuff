Straight-line motion

In this chapter
  • The three defining equations, and where the third one comes from

  • Choosing the limits of integration
  • Reading and drawing motion graphs

A particle moving along a straight line needs only one number to say where it is: its position \(s\), measured from a fixed origin, with one direction chosen as positive. Every idea in the rest of the course is a dressed-up version of this chapter, so it pays to get it rock solid.

Three definitions

\[ v = \frac{ds}{dt} \qquad\qquad a = \frac{dv}{dt} \qquad\qquad a\,ds = v\,dv \]

The first two are definitions: velocity is how fast position changes, and acceleration is how fast velocity changes. The third is not a new law. It is the second one rewritten with the chain rule:

\[ a = \frac{dv}{dt} = \frac{dv}{ds}\cdot\frac{ds}{dt} = \frac{dv}{ds}\,v \quad\Longrightarrow\quad a\,ds = v\,dv \]
Why we need the third one

Sometimes the acceleration is given as a function of position, as with a spring, which pushes harder the further you stretch it. Then \(a = dv/dt\) is useless, because you cannot integrate a function of \(s\) with respect to \(t\). The chain-rule form swaps time out for position, so you can separate the variables and integrate.

Which equation? Look at what \(a\) depends on

The single most useful question in L02–L03 is “what is the acceleration a function of?” The answer tells you which equation to separate.

Common slip

The constant-acceleration equations are only allowed when \(a\) really is constant. L03’s key outputs say it plainly: acceleration does not have to be constant. If \(a\) contains \(t\), \(v\) or \(s\), you must integrate.

Choosing limits of integration

Each integral has limits on both sides, and the limits on the two sides must describe the same two moments. The lower limits are the starting state, and the upper limits are the state you want.

\[ \int_{v_0}^{v} dv = \int_{0}^{t} a\,dt \qquad\text{reads as}\qquad \text{“from when the speed was } v_0 \text{ at } t=0, \text{ to when it is } v \text{ at time } t\text{”} \]

If you know the end state (say the particle stops, so \(v = 0\)), put that number in as the upper limit directly.

Worked example 2.1: acceleration that depends on time

Final exam 2019, Q1 (Review lecture 2)

A particle is fired into a long test chamber at \(v_0 = 27\) m/s when \(t = 0\). Its acceleration is \(a = -6t\) m/s². Ignoring gravity, how far does it travel before it stops?

  1. \(a\) depends on \(t\), so start from \(a = dv/dt\) and separate:
    \[ \int_{27}^{v} dv = \int_0^t -6t\,dt \;\Rightarrow\; v = 27 - 3t^2 \]
    Time is the variable we know \(a\) in terms of, so time has to be the variable we integrate over.
  2. Find when it stops: \(0 = 27 - 3t^2 \Rightarrow t = 3\) s.“Stops” is a velocity condition, so use the velocity equation to turn it into a time.
  3. Integrate again for position:
    \[ \int_0^x ds = \int_0^3 (27 - 3t^2)\,dt = \big[27t - t^3\big]_0^3 = 81 - 27 \]
    \(v = ds/dt\), and \(v\) is now a known function of time.

x = 54.0 m

Check: the velocity never changes sign before \(t = 3\) s, so distance travelled equals displacement.

Worked example 2.2: acceleration that depends on velocity (drag)

Same idea as Tut01 Q3–Q4

A boat cuts its engine at 20 m/s. Water drag gives \(a = -0.05\,v^2\) m/s². How far does it coast, and how long does it take, to slow to 10 m/s?

  1. Distance: the question links speed to distance, so use \(a\,ds = v\,dv\):
    \[ \int_0^s ds = \int_{20}^{10}\frac{v\,dv}{-0.05v^2} = -20\big[\ln v\big]_{20}^{10} = 20\ln 2 \]
    \(a\) is a function of \(v\). The \(v\,dv\) form gives distance directly, without going through time.
  2. Time: use \(a = dv/dt\):
    \[ \int_0^t dt = \int_{20}^{10}\frac{dv}{-0.05v^2} = 20\Big[\frac1v\Big]_{20}^{10} = 20(0.1 - 0.05) \]
    Same \(a(v)\), but now time is wanted, so put \(dt\) on the other side.

s = 13.9 m, t = 1.00 s

Worked example 2.3: constant acceleration

L02 homework, M&K 2/14

A ball is thrown straight up at 30 m/s from the edge of a 60 m cliff. Find the height \(h\) it rises above the edge, and the time to reach the bottom of the cliff.

  1. Take up as positive, so \(a = -9.81\) m/s², which is constant.Gravity is the only acceleration, and near the Earth it does not change. That is the one situation where the constant-\(a\) equations are legal.
  2. At the top, \(v = 0\): \(0 = 30^2 - 2(9.81)h \Rightarrow h = 45.9\) m.We know speeds and want a distance, so use the equation without \(t\) in it.
  3. The bottom is at \(s = -60\) m: \(-60 = 30t - 4.905t^2\). Solve the quadratic and keep the positive root: \(t = 7.70\) s.Measuring \(s\) from the cliff edge means the bottom is negative. Signs carry the direction, so there is no need to split the trip into up and down legs.

h = 45.9 m (matches the homework answer), t = 7.70 s

Motion graphs

L03 treats graphs as calculus you can see. Two facts do all the work: the slope of a graph is the next quantity down the chain, and the area under a graph is the change in the quantity above it.

Why the a–s area gives ½v²

Integrate \(a\,ds = v\,dv\) on both sides: \(\int a\,ds = \tfrac12 v^2 - \tfrac12 v_0^2\). So the area under an \(a\)–\(s\) graph is not a velocity. It is the change in \(\tfrac12v^2\). That is exactly how you build the \(v\)–\(s\) graph in Tut01 Q2: add up the area as you go, then take a square root.

Drawing a graph from the one above it: a checklist

  1. Split the time axis wherever the given graph changes formula.
  2. Integrating raises the power by one. A constant becomes a sloped line, and a sloped line becomes a parabola.
  3. Carry the end value of each piece into the start of the next. The curve never jumps (unless there is an impact).
  4. Label the key values at every break point, and mark maxima. Where \(v=0\), the \(s\)–\(t\) curve is flat.
In one breath
  • \(v=ds/dt\), \(a=dv/dt\), \(a\,ds=v\,dv\). The third is the chain rule.
  • Ask what \(a\) depends on, then separate the matching equation.
  • Limits on both sides describe the same two moments.
  • Slope goes down the chain, area goes back up it.
