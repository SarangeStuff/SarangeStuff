Newton’s three laws, in one line each

  1. First law: with no net force, a particle stays at rest or keeps moving in a straight line at constant speed.
  2. Second law: a net force causes an acceleration in the same direction, \(\sum\vec F = m\vec a\).
  3. Third law: two bodies push on each other with equal and opposite forces along the same line.

The first and third laws were the whole of statics. The second law is the whole of dynamics. It only fails near the speed of light or at atomic sizes, which never come up here.

The free-body diagram and the kinetic diagram

Draw the body on its own, cut free from everything it touches. Then put on it every force that acts on it:

  • its weight \(W = mg\), straight down from the mass centre;
  • a normal force \(N\) at each contact, perpendicular to the surface;
  • friction \(F_f\) at each rough contact, along the surface;
  • tensions along each rope, pulling away from the body;
  • any applied force.

Next to it, draw the kinetic diagram: the same body with only one arrow, \(m\vec a\), in the direction the body accelerates. Newton’s second law says the two pictures are equivalent: the forces on the left add up to the \(m\vec a\) on the right.

Why two pictures (and why your notes use one)

L19 draws the “inertial force” \(m\vec a\) on the same diagram as the forces. That is fine, but it tempts you to treat \(m\vec a\) as one more force and add it to the others. Drawing it on its own picture, with an equals sign between, makes the equation \(\sum F = ma\) visible: sum everything on the left, and set it equal to what is on the right, component by component.

The strategy (L19)

  1. Choose axes that line up with the acceleration (along and across a slope, for example).Then one equation contains the acceleration and the other has \(ma = 0\).
  2. Draw the FBD and the kinetic diagram.
  3. Write \(\sum F_x = ma_x\) and \(\sum F_y = ma_y\), stating which way is positive for each.
  4. Bring in kinematics if needed: a constant-\(a\) equation, a rope constraint (Chapter 5), or \(a\,ds = v\,dv\).

Worked example 12.1: dragging a crate up a slope

L19 Example 2

A motor winds in a cable with constant acceleration so that a 20 kg crate moves 6 m up a 30° incline in 3 s, starting from rest. \(\mu_k = 0.3\). Find the cable tension.

{{fig:k_crate_fbd}}={{fig:k_crate_kd}}
  1. Kinematics first: \(s = \tfrac12 a t^2 \Rightarrow 6 = \tfrac12 a (3)^2\), so \(a = 1.33\) m/s² up the slope.The question gives a distance and a time, which is a constant-acceleration statement. Find \(a\) before touching the forces.
  2. Across the slope (\(a_y = 0\)): \(N - mg\cos30^\circ = 0\), so \(N = 169.9\) N.
  3. Friction while sliding: \(F_f = \mu_k N = 50.97\) N.
  4. Along the slope, up positive: \(T - F_f - mg\sin30^\circ = ma\), so \(T = 50.97 + 98.1 + 26.67\).Three things must be paid for: friction, the slope component of the weight, and the acceleration itself.

T = 176 N

Friction: first ask “will it move?”

Static friction is a reaction. It is only as big as it needs to be, up to a limit of \(\mu_s N\). Kinetic friction, once sliding, is fixed at \(\mu_k N\). So L20 starts every friction question the same way:

  1. Assume the body stays still (\(a = 0\)) and work out the friction force that would be needed.
  2. Compare it with the maximum available, \(\mu_s N\).
  3. If needed ≤ available, nothing moves and \(a = 0\). If needed > available, it slides: use \(F_f = \mu_k N\), opposite to the sliding.
Common slip

Writing \(F_f = \mu_s N\) for a body that is not sliding. That is only true at the very point of slipping. The memos give a mark for showing the inequality (needed vs maximum).

Worked example 12.2: will the block move?

Final exam 2023, Q6 (Review lecture 2)

A 25 kg block has a pulley on it. A cable pulled with \(T = 40\) N at 30° above horizontal loops round the pulley and a fixed pulley, so the block feels two horizontal cable pulls of \(T\) plus the inclined pull. \(\mu_s = 0.20\), \(\mu_k = 0.15\). Find the block’s acceleration.

  1. Vertical (\(a_y = 0\)): \(T\sin30^\circ + N - mg = 0\), so \(N = 245.3 - 20 = 225.3\) N.The upward part of the pull lifts some of the weight off the floor, which reduces friction.
  2. Static check: friction needed to hold it is \(2T + T\cos30^\circ = 114.6\) N. Maximum available is \(\mu_s N = 45.05\) N. Needed > available, so the block moves.
  3. Moving: \(2T + T\cos30^\circ - \mu_k N = ma\), so \(114.6 - 33.8 = 25a\).

a = 3.23 m/s² (memo: 3.23 m/s²)

Worked example 12.3: two bodies tied by a pulley

L20 Example 2

Block A (60 kg) is on a 30° slope (\(\mu_s = 0.25\), \(\mu_k = 0.20\)). Its cable runs over a fixed pulley and down to a movable pulley that carries cylinder B (20 kg). Released from rest, find both accelerations and the tension.

  1. Constraint (Chapter 5): B hangs on a movable pulley, so \(a_A = 2a_B\).The rope loops round B’s pulley, so B moves half as far as A.
  2. Static check: holding B needs \(2T = m_Bg\), so \(T = 98.1\) N. A would then need \(294.3 - 98.1 = 196.2\) N of friction, but only \(\mu_s(509.7) = 127.4\) N is available. So A slides down the slope.
  3. B, up positive: \(2T - m_Bg = m_Ba_B\). A, down the slope positive: \(m_Ag\sin30^\circ - T - \mu_k N = m_A a_A\).
  4. Substitute \(a_A = 2a_B\) and solve the two equations together.

aA = 1.45 m/s², aB = 0.725 m/s², T = 105 N

Worked example 12.4: a force that depends on speed

L19 Example 1

A 105 000 kg orbiter deploys its parachute at 320 km/h and drops it at 55 km/h. The drag is \(F_D = 105v^2\) N. How far does it travel meanwhile?

  1. Newton: \(-105v^2 = 105\,000\,a\), so \(a = -v^2/1000\).
  2. \(a\) depends on \(v\) and we want a distance, so use \(a\,ds = v\,dv\) (Chapter 2):
    \[ \int_0^s ds = \int_{88.9}^{15.3} -\frac{1000}{v}\,dv = 1000\ln\frac{88.9}{15.3} \]
    This is the Chapter 2 decision table again. Newton’s law only supplies the formula for \(a\).

s = 1761 m

In one breath
  • FBD (every force) = kinetic diagram (\(m\vec a\)). Choose axes along the acceleration.
  • Friction: check “will it move?” with \(\mu_s N\) first. If it slides, use \(\mu_k N\) against the sliding.
  • Connected bodies: one FBD per body, plus the rope constraint.
