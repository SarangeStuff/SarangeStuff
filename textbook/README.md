# MEC2047 Kinematics Companion

A plain-language textbook for MEC2047S Dynamics I, Part I (kinematics, lectures L01–L17),
focused on drawing relative velocity and acceleration vector diagrams.

- `dist/mec2047-kinematics-companion.html` – the built book (open in a browser).
- `src/` – chapter sources (`ch*.html`) and the page shell.
- `mech.py` – solves every worked example (velocities, accelerations, ω, α).
- `figs.py`, `svgkit.py` – draw the mechanisms and to-scale vector diagrams as SVG.
- `build.py` – assembles the book: `python3 textbook/build.py`.
