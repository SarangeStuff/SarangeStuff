Solution

Question 1a

[a is given as a function of v and we want v at a position, so use v dv = a dx]

$a = v\dfrac{dv}{dx} = -k\sqrt{v}$ {{t}}
$\displaystyle\int_{81}^{v} v^{1/2}\,dv = -k\int_{0}^{x} dx$ {{t}}
$\tfrac{2}{3}\left(v^{3/2} - 81^{3/2}\right) = -kx$ {{t}} ……[1]
At $x = 18$ m, $v = 36$ m/s: $\tfrac{2}{3}\left(216 - 729\right) = -342 = -18k$ {{t}}
$k = 19\ \text{m}^{1/2}/\text{s}^{3/2}$ {{t}}
From [1] at $x = 20$ m: $v^{3/2} = 729 - \tfrac{3}{2}(19)(20) = 159$ {{t}}
$v = 159^{2/3} = 29.3\ \text{m/s}$ {{t}}

Question 1b

[now we want time, so use a = dv/dt]

$a = \dfrac{dv}{dt} = -k\sqrt{v}$ {{t}}
$\displaystyle\int_{81}^{v} v^{-1/2}\,dv = -k\int_{0}^{t} dt \;\Rightarrow\; 2\left(\sqrt{v} - 9\right) = -kt$ {{t2}}
At rest, $v = 0$: $t = \dfrac{2(9)}{k} = \dfrac{18}{19}$ {{t}}
$t = 0.947\ \text{s}$ {{t}}

Solution

Variables

Datum at the fixed ceiling; $y_C$ locates the small moving pulley C and $y_D$ the pulley D carrying W {{t2}}

[Other choices of datum are fine. Segments are taken as vertical, as usual for pulley problems.]

Cable 1 (blue)

Drum → over the top fixed pulley → down to C → up around the second fixed pulley → down to the hub of C. Three of its segments end on C:

The drum draws in cable, so $\dot L_1 = -180$ mm/s {{t}}

Cable 2 (green)

$L_2 = (y_D - y_C) + y_D + \text{constant}$ {{t}}

Constant speed, so $h = |\dot y_D|\,t = 30(10) = 300$ mm = 0.3 m (upwards) {{t}}

Solution

O at the origin, B at $(-75,\ 100)$ mm, so $OB = 125$ mm. Triangle OAB is isosceles ($OA = AB = 300$ mm).
OB makes $180^\circ - \tan^{-1}\tfrac{100}{75} = 126.87^\circ$ with the $+x$ axis; $\cos\angle AOB = \dfrac{62.5}{300} \Rightarrow \angle AOB = 77.98^\circ$ {{t}}
OA is at $126.87^\circ - 77.98^\circ = 48.89^\circ$ above the horizontal {{t}}
$v_A = \omega_{OA}\,r_{OA} = 2(0.3) = 0.6$ m/s {{t}}, perpendicular to OA (down and to the right) {{t}}
IC of AB (C): on the line through A perpendicular to $v_A$ (OA extended) and on the line through B perpendicular to $v_B$ (vertical) {{t}}
At $x = -75$ mm on line OA: $y = -75\tan 48.89^\circ = -86.0$ mm, so C = $(-75,\ -86.0)$ mm {{t}}
$r_{A/C} = 300 + \dfrac{75}{\cos 48.89^\circ} = 300 + 114.1 = 414.1$ mm; $\;r_{B/C} = 100 + 86.0 = 186.0$ mm {{t}}
$\omega_{AB} = \dfrac{v_A}{r_{A/C}} = \dfrac{0.6}{0.4141} = 1.449$ rad/s CW {{t}}
$v_B = \omega_{AB}\,r_{B/C} = 1.449(0.186) = 0.270$ m/s → {{t}}

Solution

[The figure is not to scale; work from the given angles.]

BA points at $240^\circ$; with $\beta = 75^\circ$ between the links, BC points at $240^\circ + 75^\circ = 315^\circ$, i.e. CB is $45^\circ$ below the horizontal. {{t}}

a)

$\vec v_B = \vec v_A + \vec v_{B/A}$ {{t}}
$v_A = 1$ m/s ←; $\;\vec v_{B/A} \perp AB$ (along $150^\circ/330^\circ$); $\;\vec v_B \perp CB$ (along $45^\circ/225^\circ$) {{t}}
Velocity polygon (scale 1 cm = 0.5 m/s) {{t}}
Angles: $45^\circ$ at o, $30^\circ$ at a, so $105^\circ$ at b.
Sine rule: $\dfrac{v_B}{\sin 30^\circ} = \dfrac{v_A}{\sin 105^\circ} = \dfrac{v_{B/A}}{\sin 45^\circ}$
$v_{B/A} = \dfrac{1\,\sin 45^\circ}{\sin 105^\circ} = 0.732$ m/s {{t}}
$\omega_{AB} = \dfrac{v_{B/A}}{AB} = \dfrac{0.732}{0.5} = 1.46$ rad/s CW {{t}}

[$\vec v_{B/A}$ points down-right at B, which turns AB clockwise]

b)

$v_B = \dfrac{1\,\sin 30^\circ}{\sin 105^\circ} = 0.518$ m/s {{t}}
$\omega_{CB} = \dfrac{v_B}{CB} = \dfrac{0.518}{0.25} = 2.07$ rad/s CCW {{t}}

c)

$(\vec a_B)_n + (\vec a_B)_t = \vec a_A + (\vec a_{B/A})_n + (\vec a_{B/A})_t$ {{t}}
$a_A = 0.25$ m/s² ← {{t}}
$(a_{B/A})_n = \omega_{AB}^2\,AB = (1.464)^2(0.5) = 1.072$ m/s², from B towards A ($240^\circ$) {{t}}
$(a_B)_n = \omega_{CB}^2\,CB = (2.071)^2(0.25) = 1.072$ m/s², from B towards C ($315^\circ$) {{t}}
$(\vec a_{B/A})_t \perp AB$ and $(\vec a_B)_t \perp CB$: directions known, sizes unknown {{t}}
Acceleration polygon (scale 1 cm = 0.2 m/s²) {{t3}}
Diagram:
+1 Direction of $(a_{B/A})_t$
+1 Direction of $(a_B)_t$
+1 Correct proportion
From the diagram: $(a_{B/A})_t = 1.01$ m/s² [Accept: 0.95 – 1.06] {{t}}
$\alpha_{AB} = \dfrac{(a_{B/A})_t}{AB} = \dfrac{1.01}{0.5} = 2.01$ rad/s² CW [Accept: 1.9 – 2.1] {{t}}

d)

From the diagram: $(a_B)_t = 0.952$ m/s² [Accept: 0.90 – 1.00] {{t}}
$\alpha_{CB} = \dfrac{(a_B)_t}{CB} = \dfrac{0.952}{0.25} = 3.81$ rad/s² CCW [Accept: 3.6 – 4.0] {{t}}

[Senses: $(a_{B/A})_t$ points down-right at B (CW for AB); $(a_B)_t$ points down-left at B, which is up-left of C (CCW for CB). Solving the two component equations exactly gives the same values: $\alpha_{AB} = 2.011$ CW and $\alpha_{CB} = 3.807$ CCW.]

Solution

[O is the drum's mass centre, so $\sum M_O = I_O\alpha$ holds even though O moves with the carriage. The bearing forces and the weight pass through O.]

Angular impulse–momentum about O: $I_O\omega_1 + \displaystyle\int \sum M_O\,dt = I_O\omega_2$ {{t}}
$I_O = m k_O^2 = 800(0.48)^2 = 184.3$ kg·m² {{t}}
$\sum M_O = -T r = -400(0.5) = -200$ N·m (CW) {{t}}
(↺ +ve) $\;184.3(3) - 200(10) = 184.3\,\omega_2$ {{t}}
$\omega_2 = -7.85$ rad/s {{t}}
$\omega = 7.85$ rad/s CW {{t}}

[The carriage's speed and mass only change the linear motion of the system; they do not enter the drum's spin.]

{{crop:Q6}}

Solution

a)

Tension T along cable A {{t}}; weight $W = mg$ at G {{t}}

b)

$\vec a_A \perp$ cable A (ω = 0 just after the break, so A has no normal component) {{t}}
$(\vec a_{G/A})_t = \alpha(l/2)$, vertical at G {{t}}

c)

Kinematics with ω = 0: $\vec a_G = \vec a_A + \vec\alpha\times\vec r_{G/A}$, so $a_{Gx} = -a_A\cos 30^\circ$ and $a_{Gy} = -a_A\sin 30^\circ - \alpha\,\tfrac{l}{2}$ (taking $a_A$ down-left and α CW) {{t}}
(→ +ve) $\sum F_x = m a_{Gx}$: $\;-T\cos 60^\circ = -m a_A\cos 30^\circ$ {{t}}
$a_A = 0.5774\,T/m$ {{t}}
(↑ +ve) $\sum F_y = m a_{Gy}$: $\;T\sin 60^\circ - mg = m\left(-a_A\sin 30^\circ - \alpha\tfrac{l}{2}\right)$ {{t}}
(↻ +ve) $\sum M_G = I_G\alpha$: $\;T\sin 60^\circ\left(\tfrac{l}{2}\right) = \tfrac{1}{12}ml^2\,\alpha$ {{t}} {{t}}
$\alpha\tfrac{l}{2} = \dfrac{3T\sin 60^\circ}{m} = 2.598\,T/m$ {{t}}
Substituting: $\;0.866\,T - mg = -0.5(0.5774\,T) - 2.598\,T$ {{t}}
$3.753\,T = mg$ {{t}}
$T = \dfrac{150(9.81)}{3.753} = 392$ N {{t}}

[The length l cancels. Check: $a_A = 1.51$ m/s² and $\alpha l/2 = 6.79$ m/s², both positive, so the assumed senses were right.]

Solution

Positions and spring states shown in the diagram above (mm) {{t}}
$T_1 + V_1 + U'_{1-2} = T_2 + V_2$, with $T_1 = 0$ and $U'_{1-2} = 0$ (no friction) {{t}}
At equilibrium the spring is compressed by $\delta_{st} = \dfrac{mg}{k} = \dfrac{2(9.81)}{1600} = 12.26$ mm {{t}}
State 1 (40 mm above equilibrium): stretched by $x_1 = 40 - 12.26 = 27.74$ mm {{t}}
State 2 (6 mm below equilibrium): compressed by $x_2 = 6 + 12.26 = 18.26$ mm {{t}}
Datum at state 2, so $h = 40 + 6 = 46$ mm: $(V_g)_1 = mgh = 2(9.81)(0.046) = 0.9025$ J {{t}}
$(V_e)_1 = \tfrac{1}{2}kx_1^2 = \tfrac{1}{2}(1600)(0.02774)^2 = 0.6155$ J {{t}}
$(V_e)_2 = \tfrac{1}{2}(1600)(0.01826)^2 = 0.2668$ J {{t}}
$0 + 0.9025 + 0.6155 = \tfrac{1}{2}(2)v^2 + 0.2668$ {{t}}
$v = 1.119$ m/s {{t}}

[Shortcut: measure x from the equilibrium position and the weight and spring preload cancel: $\tfrac{1}{2}mv^2 = \tfrac{1}{2}k\left(0.040^2 - 0.006^2\right) = 1.251$ J, which gives the same $v = 1.119$ m/s.]
