# Polar and 3D coordinates study guide (MEC2047S L06–L08)

Source for the bookmarked PDF guide. Build with

    python3 guides/polar/build_polar.py <dir-with-slide-jpegs>

then print `dist/polar-3d-coordinates-guide.html` to PDF. The slide snapshots come
from your own lecture PDFs and are embedded only in `dist/`, which is not committed.
