Question 2 [10] · rope with a slanted segment

Datum at the pulley P. x = horizontal distance of A from P's vertical; $y_B$ = depth of B below P (down +). Diagram {{t2}}
$L = \sqrt{x^2 + h^2} + y_B = $ constant, with h = 2 m {{t}}

[Why Pythagoras: the rope from P to A is slanted, so its length is the hypotenuse of the x–h triangle. The velocity-line trick only works for parallel strands.]

Differentiate: $0 = \dfrac{x\dot x}{\sqrt{x^2 + h^2}} + \dot y_B$ {{t}}
At x = 1.5 m, S = 2.5 m and $\dot x = +1.5$: $\;\dot y_B = -\dfrac{1.5(1.5)}{2.5} = -0.9$ m/s {{t}}
$y_B$ is measured downwards, so −0.9 means B rises at 0.9 m/s {{t}}
Differentiate again (with $\ddot x = 0$): $\;\ddot y_B = -\left[\dfrac{\dot x^2}{S} - \dfrac{x^2\dot x^2}{S^3}\right]$ {{t2}}
$= -\left[\dfrac{2.25}{2.5} - \dfrac{2.25(2.25)}{15.625}\right] = -0.576$ m/s² {{t}}
So B accelerates upwards at 0.576 m/s² {{t}}

[Sense check: as A moves further out, the slanted rope lengthens faster, so B's upward speed grows. That's an upward acceleration ✓ (the same idea as S25 Q2c).]

Question 6 [12] · particle work–energy with friction and a spring

(a) From rest (1) to touching the spring (2)

$T_1 + V_1 + U'_{1\text{-}2} = T_2 + V_2$ {{t}}
$N = mg\cos 30° = 33.98$ N, so $F = \mu_k N = 8.50$ N, acting up the slope {{t}}

[Why up the slope: kinetic friction always opposes the sliding, and the block slides down. Why N = mg cos 30°: there's no acceleration ⊥ to the incline, so N balances the perpendicular part of the weight.]

Gravity: the block drops $1.2\sin 30° = 0.6$ m, so $\Delta V_g = 4(9.81)(0.6) = 23.54$ J released. Friction: $U' = -8.50(1.2) = -10.19$ J {{t}}

[Why negative: friction points opposite to the motion, so its work is −F × distance. It never gives energy back.]

$0 + 23.54 - 10.19 = \tfrac12(4)v_2^2$, so $v_2 = 2.58$ m/s {{t}}

(b) From rest (1) to maximum compression (3)

Total slide = 1.2 + x, and $T_1 = T_3 = 0$ (at rest at both ends) {{t}}
Gravity released: $mg\sin 30°\,(1.2 + x) = 19.62(1.2 + x)$ {{t}}
Friction work: $-8.50(1.2 + x)$ (it acts the whole way, spring or no spring) {{t}}
Spring: $V_{e3} = \tfrac12 kx^2 = 750x^2$; $\;V_{e1} = 0$ {{t}}

[Why only x: spring energy depends on the change from the natural length. The spring is uncompressed until the block reaches it.]

$11.12(1.2 + x) = 750x^2 \;\Rightarrow\; 750x^2 - 11.12x - 13.35 = 0$ {{t}}
$x = \dfrac{11.12 + \sqrt{11.12^2 + 4(750)(13.35)}}{1500} = 0.141$ m (141 mm) {{t}}

[Why the + root: a compression must be positive. The other root (−0.126) has no physical meaning here. Check: $11.12(1.341) = 14.92$ J and $750(0.141)^2 = 14.92$ J ✓]

(c) Does it stay?

At maximum compression the spring pushes up the slope with $kx = 1500(0.141) = 211.5$ N, against $mg\sin 30° + \mu_s N = 19.62 + 10.19 = 29.8$ N {{t}}
211.5 N ≫ 29.8 N, so the block slides back up the incline {{t}}

[Why friction now points down the slope: the block is about to move up, so static friction opposes that and acts down the slope, helping gravity hold it. It still can't hold it.]
